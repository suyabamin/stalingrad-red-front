# Controls

| Action | Key |
| --- | --- |
| Move | W, A, S, D |
| Jump | Space |
| Sprint | Shift |
| Release mouse | Escape |
| Capture mouse | Click in the game window |

Mouse sensitivity is exposed by the `SettingsManager` autoload through `set_mouse_sensitivity(value)`. Its initial value is 0.0025 radians per mouse-motion unit.
